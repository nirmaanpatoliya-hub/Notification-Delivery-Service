Mock Providers & Failover

Each channel has a primary (priority 1) and backup (priority 2) provider. When a provider fails 2 times consecutively, the circuit opens for 30s.

API Key Settings

DakGhar enforces permissions using two separate secret keys sent in request headers. Keys are stored only in sessionStorage for this browser session and sent to the DakGhar API in request headers (X-Api-Key or X-Admin-Key). They are cleared when the browser tab closes.

No Sender Key
Used for enqueuing messages and viewing outbox/providers. Sent via X-Api-Key.
No Admin Key
Required for pausing/resuming the worker, manual tick, simulated outages, and fail-rate updates. Sent via X-Admin-Key.
