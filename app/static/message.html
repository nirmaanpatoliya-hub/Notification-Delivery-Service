API Key Settings

DakGhar enforces permissions using two separate secret keys sent in request headers. Keys are stored only in sessionStorage for this browser session and sent to the DakGhar API in request headers (X-Api-Key or X-Admin-Key). They are cleared when the browser tab closes.

No Sender Key
Used for enqueuing messages and viewing the outbox. Sent exclusively via the X-Api-Key header.
No Admin Key
Used for worker pause/resume, single tick, provider outage switches, and database reset. Sent exclusively via the X-Admin-Key header.
